# Hi, I’m Akash 👋

I’m a Product Manager at LinkedIn working on AI-powered job discovery. Outside work, I build small AI agents to get hands-on with how they use tools, where they fail, and what it takes to make them reliable.

## 🔭 What I’m building and learning

My goal is to get good at designing, evaluating, and shipping AI agents. A few things I want to get better at:

- **Tools, memory, and workflows** — connecting models to APIs and live data, carrying context across sessions, and figuring out when an agent should act or ask for help.
- **Evals and reliability** — turning real tasks into test cases, measuring whether the agent actually finished the job, and using failures to decide what to improve.
- **Models and agent harnesses** — comparing quality, latency, and cost across models and seeing how much better tools, prompts, and verification can improve the same model.
- **Multimodal and computer use** — exploring how agents can work with images, screenshots, and browser interfaces.

## 🛠️ Projects and tools

I’ve started prototyping with **Hugging Face smolagents**. I’m also learning the **OpenAI Agents SDK**, **Google Agent Development Kit (ADK)**, and **LangGraph**. I want to try similar workflows across them and see how each handles tool calling, state, and debugging.
